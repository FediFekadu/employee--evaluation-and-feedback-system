## ✅ Core Principle (Very Important)

**A teacher’s performance is calculated ONCE per teacher per semester.**

Even though:

* students evaluate **per course**
* peers evaluate **once per semester**
* HOD evaluates **once per semester**

👉 **All evaluations are normalized to ONE semester score per teacher.**

---

## 1️⃣ What is the “Final Result”?

**Final Result = Teacher’s overall performance in ONE semester**

This single result is a **weighted combination** of:

* Student evaluations
* Peer (teacher-to-teacher) evaluations
* HOD evaluation

---

## 2️⃣ Weight Structure (Fixed Rule)

These weights never change:

| Evaluation Source | Weight   |
| ----------------- | -------- |
| Students          | 50%      |
| Peer teachers     | 30%      |
| HOD               | 20%      |
| **Total**         | **100%** |

---

## 3️⃣ Student Evaluation (Per course → One semester score)

This is the **only part done per course**, so we must carefully combine it.

### Scenario

A teacher teaches multiple courses in one semester, for example:

* Course A (Year 2)
* Course B (Year 3)
* Course C (Year 4)

Each course has **many students**, and each student submits an evaluation.
so when department choose instructor/teacher and release a evaluation or post it appear for student with the course he assigned for example if that teacher is not teaches/assigned for year 3 students they do not evaluate that teacher.
---

### 🔹 Step 1: Course-level score

For **each course**, calculate the average of all student evaluations.

Example:

* Course A → 78%
* Course B → 85%
* Course C → 80%

---

### 🔹 Step 2: Semester-level student score

Now combine all courses taught by the teacher **in that semester**:

[
\text{Student Score} = \frac{78 + 85 + 80}{3} = 81%
]

✅ This **81%** is the **student evaluation score for that teacher for the semester**
(important: **not per course anymore**)

---

### 🔹 Step 3: Apply student weight (50%)

[
\text{Weighted Student Score} = 81 \times 0.50 = 40.5
]

---

## 4️⃣ Peer-to-Peer Evaluation (Once per semester)

* Done **once per semester**
* Can be evaluated by **one or multiple peers**

If multiple peers evaluate:
[
\text{Peer Score} = \text{average of all peer scores}
]

Example:

* Peer Score = 75%

Apply weight:
[
75 \times 0.30 = 22.5
]

---

## 5️⃣ HOD Evaluation (Once per semester)

* Done **once per semester**
* Single score

Example:

* HOD Score = 90%

Apply weight:
[
90 \times 0.20 = 18
]

---

## 6️⃣ ✅ Final Semester Result (KEY FORMULA)

Final Semester Score=(Student Score×0.50)+(Peer Score×0.30)+(HOD Score×0.20)

### Example Calculation:

* Student: 40.5
* Peer: 22.5
* HOD: 18

[
40.5 + 22.5 + 18 = \boxed{81%}
]

---

## 🎯 Final Definition (One-line, very clear)

> **A teacher is evaluated once per semester.
> Student evaluations from multiple courses are averaged into one semester student score, then combined with peer and HOD evaluations using fixed weights (50–30–20) to produce the final semester performance result.**
