# ✅ **STUDENT DASHBOARD — Tasks & Features**

## ⭐ 1. Dashboard Overview

* Student profile summary (name, ID, department, year, semester)
* Quick stats:

  * Total courses this semester
  * Evaluations pending
  * Evaluations completed
  * Notifications
* Reminder alerts (e.g., “Please evaluate your instructors”)

---

## ⭐ 2. View Courses

* List of all enrolled courses
* View course details:

  * Instructor name
  * Credit hours
  * Schedule
* Download course outline (if provided)
* Filter by semester/year

---

## ⭐ 3. Evaluate Teacher / Course

* Show list of instructors to evaluate
* Form with rating scales (1–5)
* Question categories (teaching quality, punctuality, communication, engagement, etc.)
* Comment section
* Submit anonymous feedback
* Show “Evaluation Completed” badge
* Prevent multiple submissions

---

## ⭐ 4. Check Evaluation Status

* See which instructors are already evaluated
* See which evaluations are pending
* Progress bar showing completion percentage
* Evaluation deadlines

---

## ⭐ 5. View Announcements

* Department announcements
* College announcements
* Instructor announcements
* Notification center
* Mark notifications as read

---

## ⭐ 6. Student Feedback History (Optional)

* View submitted evaluations (only status, not detailed — to keep anonymity)
* Show dates when evaluations were completed

---

## ⭐ 7. Vote for Best Teacher / Best Department Head (if enabled)

* Voting list
* Vote anonymously
* Show “Your vote is submitted”
* View voting rules

---

## ⭐ 8. View Profile

* Name, department, year, semester
* Student ID and account info
* Option to update profile picture (if allowed)

---

## ⭐ 9. Settings

* Change password
* Notification preferences
* Language preference (if multilingual system)

---

**Copy & paste this prompt:**

---

### 🚀 **Student Dashboard UI Prompt**

> **Create a modern, visually attractive Student Dashboard UI for a “Student Feedback and Teacher Evaluation System.”**
>
> The UI should be clean, simple, smart, and designed for students to easily complete evaluations and navigate their courses.
>
> **The dashboard should include these sections:**
>
> * Dashboard Overview (courses, evaluations pending/completed, notifications)
> * My Courses (list of enrolled courses with instructor names)
> * Evaluate My Instructors (evaluation form, progress, deadlines)
> * Evaluation Status (completed/pending)
> * Announcements & Notifications
> * Voting Module (vote for best teacher or head)
> * Profile & Settings
>
> **UI Requirements:**
>
> * Clean sidebar navigation with icons
> * Beautiful card-based layout
> * Soft shadows, rounded corners (xl / 2xl)
> * Easy-to-read typography
> * tables for course listing
> * Modal popups for evaluation forms
> * Progress bar showing evaluation completion
> * Notification bell with dropdown
>
> **Design Style:**
>
> * Minimal but modern
> * Inspired by student portals & university apps
> * Soft colors, clean layout, balanced spacing
> * Smooth transitions and animations
>
> **Output:**
>
> * Full UI layout description
> * Component breakdown
> * Navigation structure
> * Suggested color scheme
>
> The UI should feel friendly, motivating, and easy to use for students while still looking premium and professional.
